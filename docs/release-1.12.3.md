**Nine new languages** – NeonPlan 3D now speaks 16 languages.

### New

- **Danish, Swedish, Norwegian (Bokmål and Nynorsk), Finnish, Czech, Polish, Romanian and Slovenian.** NeonPlan 3D follows the language of your Home Assistant user (profile → language); a language file is only fetched when it is needed, so the bundles stay small for old, weak wall tablets. Thanks to **zanzei26** for the Norwegian translation it builds on (#233).
- The setup dialog of the integration is now translated into every language as well.

Native speakers welcome: if a text sounds odd in your language, please open an issue or a discussion – a quick note with the better wording is enough.

### Fixed

- French, Spanish, Dutch, Italian and Hungarian: the restart notice shows both versions again.

### How to update

Settings → System → Updates. If NeonPlan 3D is missing there: HACS → NeonPlan 3D → ⋮ → **Update information** → **Download**. Then restart Home Assistant and reload the page (Ctrl+F5).

**Neun neue Sprachen** – NeonPlan 3D spricht jetzt 16 Sprachen.

### Neu

- **Dänisch, Schwedisch, Norwegisch (Bokmål und Nynorsk), Finnisch, Tschechisch, Polnisch, Rumänisch und Slowenisch.** NeonPlan 3D folgt der Sprache deines Home-Assistant-Nutzers (Profil → Sprache); eine Sprachdatei wird nur geladen, wenn sie gebraucht wird – so bleiben die Bundles klein für alte, schwache Wandtablets. Danke an **zanzei26** für die norwegische Übersetzung, auf der sie aufbaut (#233).
- Auch der Einrichtungsdialog der Integration ist jetzt in allen Sprachen übersetzt.

Muttersprachler willkommen: Klingt ein Text in deiner Sprache seltsam, mach gern ein Issue oder eine Diskussion auf – ein kurzer Hinweis mit der besseren Formulierung reicht.

### Behoben

- Französisch, Spanisch, Niederländisch, Italienisch und Ungarisch: Der Neustart-Hinweis zeigt wieder beide Versionen.

### So bekommst du das Update

Einstellungen → System → Updates. Fehlt NeonPlan 3D dort: HACS → NeonPlan 3D → ⋮ → **Informationen aktualisieren** → **Herunterladen**. Danach Home Assistant neu starten und die Seite neu laden (Strg+F5).
